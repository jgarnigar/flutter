# ***PRIMERA APLICACIÓN EN FLUTTER***

Esta aplicación consisten en brindar el número que aparece en la sucesión de fabonacci según la posición que el usuario ingrese. No acepta número negativos.

Por ejepmlo en la posición 0, el número que aparece en la sucesión de fabonacci es 0, en la posición 1 es 1, en la posición 2 es 1, en la posición 3 es 2, en la posición 4 es 3, en la posición 5 es 5, en la posición 6 es 8, y así sucesivamente. Nuestro programa nos brindará el número que aparece en la posición que el usuario ingrese.
